# 婚房局部翻新（主卧 / 餐厅 / 书房）

> 项目归类：装修设计（与 `output/wedding` 同级）
> 建立：2026-11-04 ｜ 状态：**M0 工具就绪，等待照片与量房数据**

## 一、项目背景与硬约束

- 婚房局部翻新，硬装基础由长辈完成，整体风格简约。
- **主卧、餐厅、书房**三间已装成品柜与桌子；**柜体不可拆**，桌子可移位/替换。
- 本次只做「表面级 + 家具级」改动：墙色、软装、灯具、局部家具；**不动水电、不拆柜、不改门窗洞**。
- 目标：与原柜体协调、简约柔和、有婚房氛围、兼顾收纳、方案可落地。

## 二、配色系统（已按你的意见调整）

主系统：**米杏 + 灰 + 黑 + 原木**；灰蓝降为可选点缀（≤10%，仅主卧）。

| 角色 | 色 | 参考值 | 用法 |
|------|----|--------|------|
| 底色 | 暖米杏 | `#E8DCC8` | 墙面、床品、纱帘 |
| 中间 | 暖白 | `#F5F1E8` | 顶面、柜门（柜体偏白时） |
| 中性 | 中灰 / 深灰 | `#9A9A96` / `#5A5A57` | 窗帘、地毯、单椅 |
| 结构线 | 近黑 | `#1F1F1D` | 细框灯具、把手、画框、椅腿 |
| 木 | 原木 / 胡桃 | `#C4A574` / `#7A5A3C` | 桌面、边几；**跟现有柜体取同族** |
| 点缀 | 香槟金 / 陶土红 | `#C9A86A` / `#A65A4A` | 五金、花器、婚房小物（克制） |

**适配规则**：先看柜体色再定方案——
- 柜体偏白/浅灰 → 米杏 60% + 灰 30% + 黑 10%；
- 柜体偏暖木 → 原木承接，米杏打底，灰 ≤20%；
- 柜体偏深 → 米杏提到 65%，灰用浅灰，黑只做线条。

## 三、三套方案（每套 × 3 房间）

| 方案 | 配比 | 气质 | 适合 |
|------|------|------|------|
| **A 米杏原木·温润** | 米杏 60 / 原木 30 / 黑 10 | 柔、暖、安静 | 主卧（首选）、餐厅 |
| **B 灰调简约·克制** | 灰 50 / 米杏 35 / 黑 15 | 利落、干净 | 书房（首选）、餐厅 |
| **C 原木黑框·静奢** | 原木 45 / 米杏 35 / 黑 20 | 有骨架感、耐看 | 书房、餐厅；主卧备选 |

婚房氛围统一靠：2700K 暖光、亚麻/羊绒织物、成对床头灯、花艺香氛、可换季的陶土红小物。
**不刷红墙、不做满墙喜字。**

## 五、工具与命令

```bash
# 平面图（含 PNG/PDF 导出、尺寸总表）
python scripts/renovation/floorplan.py draw --data output/renovation/现状_测量数据.json

# 灯光点位图（单独一层）
python scripts/renovation/floorplan.py draw --data output/renovation/现状_测量数据.json --layer lighting

# 动线自检（硬违规退出码 1）
python scripts/renovation/floorplan.py check --data output/renovation/现状_测量数据.json

# 批量出图（读任务清单，失败重试 1 次）
python scripts/renovation/render_batch.py --tasks output/renovation/效果图任务.json
```

生图默认走**指令式编辑**（`Qwen-Image-Edit-2509`）：保留原图柜体/门窗/地板，只改墙色与软装。
失败降级 `img2img`（Z-Image）。模型与 Key 见 `.claude/skills/interior-design/`。
