# 置业资产 · 财务累欠 vs 合同 对账工具

把「财务累欠明细表」（应收/实收/累欠）和「合同整理表」（合同起止/月租金）做逐房源对账，
找出：合同是否漏录、应收月份是否一致、月租金是否一致，并生成带「结论」的对账 Excel。

## 数据源（在 config.py 里改路径）

| 表 | 路径变量 | 说明 |
|----|---------|------|
| 财务累欠明细表 | `BILL` | 含「顺泰 / 置业、龙州 / 龙津」三个 sheet，每行一个房源的应收、实收、累欠 |
| 合同整理表 | `CTR` | 「导入格式」sheet，含合同起始/解除时间、月租金、房号集合、备注 |

## 运行步骤（按顺序，在项目根目录执行）

```bash
cd D:/AI/cursor/office-assistant
python scripts/asset_reconcile/step1_extract.py   # 提取两边数据 → temp/bill.json, contracts.json
python scripts/asset_reconcile/step2_match.py     # 匹配 + 整月粗算 → temp/matched.json, unmatched_*.json
python scripts/asset_reconcile/step3_refine.py    # 套用免租期精确重算 + 生成结论 → matched.json
python scripts/asset_reconcile/step4_excel.py     # 生成对账 Excel → 财务累欠表目录
python scripts/asset_reconcile/step5_verify.py    # 数据正确性校验（应全部通过）
python scripts/asset_reconcile/step6_fill.py      # 把结论回填进源表副本「应收情况」列（另存副本，不动源表）
```

> step6 用 Excel/WPS 的 COM 接口（`fill_via_com.ps1`）只改目标单元格，公式、缓存值、跨文件引用、格式全部原样保留；
> 因此机器需装有 WPS 表格或 Excel。openpyxl 直写会丢公式缓存值，不可用。

中间文件都放在 `temp/`，可删；最终产出在财务累欠表同目录（`config.py` 的 `OUT_DIR`）。

## 匹配规则（step2）

对每个财务房源找对应合同，三级信号：

1. **承租人名字**：先精确同名，再模糊（去掉「股份/有限/责任/公司」后缀和「龙岩市/福建」前缀，识别改名/简写）。
2. **面积**：同名内按面积最近邻，容差 `AREA_TOL=0.30`（30%，因为面积口径有差异）。
3. **房号（楼栋号+楼层号）**：面积失效或无面积时，用「楼栋号 + 楼层号」匹配；面积匹配时也优先房号一致的候选（消歧）。

同时要求合同期间「覆盖 2025 年」（把 2025 年应收匹配到 2025 年有效的合同，而不是 2026 年续签合同）。

## 对账口径（step3）

- 整月粗算：`月租金 × 2025年内整月数`（按合同录入起始/解除时间截取）。
- 精确重算：套用备注里的「免租期」（如 `装修免租期三个月（2025.7.1-2025.9.30）`），从应收月份里扣掉。
- 每行生成「结论」，三种类型：相符 / 月份差异 / 月租差异。

## 已知的坑（务必先了解，否则会误判）

1. **面积口径不一致（系统性）**：财务「面积」普遍比合同大 7%~30%（计费面积 vs 建筑面积），所以面积不能当唯一键。
2. **房号是两套体系**：财务 `标准厂房-7#厂房-301` ↔ 合同 `标准厂房7幢/3/南侧三层301`，楼栋编号也不完全对应。
3. **承租人改名**：财务「福建侨龙应急装备股份…」= 合同「福建侨龙应急装备…」，靠模糊匹配兜底。
4. **财务源表有重复行**：同一房源会出现 2 行（如北新联和的职工公寓），提取时按原样保留，校验用「顺序索引」而非「唯一键」。
5. **特殊房源无面积无房号**：土地/空地/车库/楼顶/整栋类，房号匹配不适用，统一进「财务有-合同无对应」人工核对。
6. **合同 2026 年起租但财务 2025 年有应收**：= 合同漏录 2025 年合同（结论里会显示「合同应收0个月」）。

## 数据正确性校验（step5，四维）

- A：财务源表 1159 行逐行逐字段回读比对（应收/实收/累欠/各月）→ 必须 0 差异。
- B：合同源表 1132 行逐字段回读比对（承租方/房号/月租/面积）→ 必须 0 差异。
- C：三大板块合计 = 源表「总计」行（应收 4380.87 / 实收 2681.90 / 累欠 8275.44 万）。
- D：匹配 + 未匹配 的数量与金额守恒。

> 「取值是否正确」由 step5 保证 100%；「哪个房源对应哪份合同」是匹配逻辑（启发式），
> 未匹配的 495 个需人工按业务确认，这一层无法 100% 自动准确。

## 输出文件（Excel 4 个 sheet）

- 「汇总」：总体统计。
- 「对账明细」：匹配房源逐行，第 3 列是**结论**（相符 / 月份差异 / 月租差异），并列出财务与合同的月份、月租、金额对照。
- 「财务有-合同无对应」：未匹配财务房源（带结论 + 候选合同）。
- 「合同有-财务无对应」：未匹配合同。
