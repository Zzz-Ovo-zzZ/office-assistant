# 4% 取钱法则（退休后安全取款）

> 你可以从投资组合中每年安全取出一定比例的资金，而不会耗尽资产。
> 安全取款率 = 年化收益率 − 通胀率。对应代码：`WealthEngine.fire_assets`。

---

## 一、基本原理

退休后每年取多少钱才既够花、又不至于提前花光本金？答案是「安全取款率」。

## 二、不同组合的安全取款率

| 投资组合 | 年化收益率 | 安全取款率 | 100 万每年可取 |
|---------|-----------|-----------|--------------|
| 100% 银行存款 | 2-4% | ~0-1% | 0-1 万 |
| 80% 债券 + 20% 股票 | 5-6% | ~2-3% | 2-3 万 |
| 60% 债券 + 40% 股票（传统） | 7% | ~4% | 4 万 |
| 90% 股票 + 10% 债券（巴菲特推荐） | 9.5% | ~6.5% | 6.5 万 |
| 100% 股票指数基金 | 10-11% | ~7% | 7 万 |

## 三、历史验证（Estrada 2015）

Javier Estrada 2015 年论文研究了 1900-1985 年的 86 个 30 年窗口期：

| 资产配置(股/债) | 失败率 | 评价 |
|---------------|--------|------|
| 100/0 | 3.5% | 可接受 |
| 90/10 | 2.3% | ✅ 推荐 |
| 80/20 | 2.3% | ✅ 推荐 |
| 70/30 | 1.2% | ✅ 推荐 |
| 60/40 | 0% | 最安全但收益低 |
| 40/60 | 3.5% | 不推荐 |
| 30/70 | 12.8% | ❌ 高失败率 |

**关键结论**：
- 90/10 方案失败率仅 2.3%，但平均剩余资产比 60/40 高 **108%**
- 债券超过 70% 时，失败率急剧上升
- 退休人士必须持有足够的股票，否则跑不赢通胀、本金会耗尽

## 四、财务自由公式

> **金融资产 × 4% + 房租 + 其它被动收入 ≥ 家庭年开支**

### 快速计算
所需金融资产 = 年开支 × 25

| 年开支 | 所需金融资产（4%法则） |
|--------|---------------------|
| 5 万 | 125 万 |
| 10 万 | 250 万 |
| 15 万 | 375 万 |
| 20 万 | 500 万 |
| 30 万 | 750 万 |
| 50 万 | 1250 万 |

> 注：已有房租、退休金等其它被动收入时，先从年开支中扣除再计算。

## 五、中国语境提示

- 原语境中的社安金/Roth 转换等美国退休税制安排，中国对应为**社保养老金 + 个人养老金**（每年 1.2 万税优）。
- 中国个人养老金账户内投资收益免税，领取时按 3% 优惠税率，适合作为「其它被动收入」的一部分。
- 4% 法则是美股长期回测的结论，中国市场波动更大、历史更短，实际可取款率建议更保守（3%-3.5%）。
