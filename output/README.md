# 输出文件目录规范

## 目录结构

```
output/
├── wedding/          # 婚嫁择日相关输出
│   ├── 八字合婚/     # 八字合婚分析报告
│   ├── 订婚择日/     # 订婚吉日筛选/扫描/推荐
│   └── 综合规划/     # 求婚/订婚/结婚完整规划
├── fitness/          # 健身饮食相关输出
│   ├── assessments/  # 身体评估报告
│   ├── plans/        # 训练计划 / 饮食计划
│   └── logs/         # 训练日志 / 饮食日志 / 进度追踪
└── README.md         # 本文件
```

## 命名规范

```
{主题}_{内容描述}_{版本/日期}.{扩展名}
```

示例：
- `身体评估_张三_20260704.md`
- `训练计划_增肌_PPL_12周.md`
- `饮食日志_2026年7月第1周.md`
- `订婚吉日_筛选结果_2026年9-12月.md`

## 原则

1. **按领域分目录** — 婚嫁/健身/办公等不同领域的输出分开放
2. **子目录不超过2层** — 避免过度嵌套
3. **文件名自解释** — 不需要打开就知道内容
4. **历史报告不删** — 保留所有版本，方便回溯对比
5. **临时草稿放 `temp/`** — 不要污染正式输出目录
