# 女朋友专区

> 为小陈定制的办公助手子目录，覆盖工作业务与个人规划。

## 目录结构

```
girlfriend/
├── work/           # 工作相关（万龄康养业务）
│   ├── 康养行业知识库.md  # 行业知识+龙岩市场情报（数据底座）
│   ├── 工作策略.md        # 完整工作方法论（核心文档）
│   ├── KK网采集方案.md    # 🆕 龙岩KK网论坛信息采集方案
│   ├── 医生信息库.md      # 医生/医院/科室联系人管理
│   ├── 拜访记录模板.md    # 每次外勤的沟通记录
│   ├── 话术参考.md        # 项目介绍 + 常见应答 + 介绍费话术
│   └── kk_data/           # 🆕 KK网采集数据存档
├── fitness/        # 健身模块（待建设，可复用项目健身引擎）
└── README.md       # 本文件
```

## 文件说明

| 文件 | 用途 | 更新频率 |
|------|------|---------|
| `康养行业知识库.md` | 行业数据+龙岩市场情报（决策底座） | 获取新数据时更新 |
| `工作策略.md` | 长期参考，方法论和渠道策略 | 策略调整时更新 |
| `KK网采集方案.md` | 🆕 龙岩本地论坛信息采集工具方案 | 每周运行1-2次 |
| `医生信息库.md` | 记录每位联系人的信息 | 每次新接触后 |
| `拜访记录模板.md` | 每次外勤的沟通纪要 | 每次外勤后 |
| `话术参考.md` | 见客户前的复习材料 | 迭代优化时更新 |

## 工具脚本

| 脚本 | 用途 | 使用方法 |
|------|------|---------|
| `scripts/utils/kk_scraper.py` | 🆕 KK网康养线索采集器 | `python scripts/utils/kk_scraper.py queries` 查看搜索URL；`parse <html>` 解析结果 |
