## 一、结论

**不卖旧买新，不走品牌店以旧换新。用老金到独立打金工坊或水贝直接熔制古法金，只付工费+损耗。**

今天（8/20）国际金价盘中破 4500 美元/盎司，国内金饰克价一夜跳涨 37–46 元：

| 口径 | 价格 |
|------|------|
| 上金所 AU9999 基准（真实金料价） | 968.5 元/克 |
| 足金 999 回收价 | ~953 元/克 |
| 周生生 / 周大福 / 老庙 / 老凤祥 | 1359 / 1355 / 1355 / 1352 元/克 |

**品牌溢价 = 1355 − 968.5 ≈ 386 元/克**，50 克就是 **1.93 万元的纯溢价**。打金路线把这部分整个省掉。

额外好处：打金是"同一块金子换个形状"，**买入价与折抵价相等，价差为 0，完全免疫金价波动**——现在是历史高位，但对你不构成影响，不需要择时。

## 二、成本对比（50 克古法五金的增量支出）

> 核心公式：**每克净成本 =（新金计价 − 旧金折抵价）+ 工费 + 损耗**
> 旧金折抵价越接近新金计价越划算。打金店两者是同一块金子，价差为 0；品牌店价差拉到最大。

| 路线 | 构成 | 增量成本 | 评价 |
|------|------|---------|------|
| **水贝定制** | 工费 ~20 元/克 + 损耗 2% | **2,000–3,000 元** | 最省，需跑深圳或找可靠寄金商家 |
| **本地打金工坊** | 工费 60–150 元/克 + 损耗 2% | **4,000–8,500 元** | ⭐ 推荐，可当面盯全程 |
| 品牌店以旧换新 | 折旧 ~200–240 元/克 + 古法工费 100–300 元/克 | 15,000–27,000 元 | 折旧费是隐形大头 |
| 卖旧买新（品牌） | 卖 47,650 元 / 买 67,750 元+ | 20,000–35,000 元 | 最差，全额吃下品牌溢价 |

**推荐路线与最差路线相差约 1.5–3 万元。**

### 古法金工费行情（2026）

| 渠道 / 工艺 | 工费 |
|------|------|
| 水贝产业带古法手镯 | 20–25 元/克 |
| 独立工坊基础古法 | 30–80 元/克 |

## 三、最大风险：你的老金"说不清"

这是本方案唯一的重大风险点，必须优先解决。

### 行业真实情况

- **XRF 光谱仪只能测表面**，检不出"金包银""金包钨"夹心，是初筛工具不是定论
- **"全程紧盯"并不足以防坑** —— 熔金时可用镊子夹走微量金液，或用同等重量其他金属蒙混
- **王水清洗会溶解黄金本体**，正确做法是高温火烧或超声波清洗
- 业内明确建议：**新旧金不要混合加工**（尤其各占一半），纯度出问题时责任说不清
- 正规机构**不应存在**折旧费、火耗费、提纯费等隐藏扣费，如有必须交易前公示

### 应对：分层处理策略

**不要把 50 克全部一锅熔。** 按印记先分三堆：

| 堆 | 判断依据 | 处理方式 |
|----|---------|---------|
| **A 堆 · 确定足金** | 印记 足金/999/9999/千足金/24K，或金条 | ✅ 用于打古法金 |
| **B 堆 · 确定非足金** | 印记 18K/750/14K/585 等 | ❌ 单独卖给正规回收，换现金 |
| **C 堆 · 无印记/存疑** | 老件、无标识、有焊点 | ⚠️ 单独送检，别混入 A 堆 |

如果 A 堆不足 40 克，宁可缩减五金克重，也不要把 C 堆混进去赌。

## 四、四步执行流程

### 第 1 步：家里先做基线（0 成本，必做）

1. 买 **0.01g 精度电子秤**，逐件称重、拍照、编号，做成表格
2. 记录每件的印记文字
3. **不要自行打磨清洗**——会磨损金体造成克重损失

### 第 2 步：独立检测（不要只信打金店）

- 找 **2–3 家**分别免费 XRF 初筛，交叉比对，结果一致性高才可信
- C 堆送 **NGTC 国检 / 中检** 等第三方机构，费用几十到几百元
- **拒绝破坏性检测**（火烧、剪开）除非事先书面同意——2026 年新规要求必须事先征得同意

### 第 3 步：选店（五查）

| 查什么 | 标准 |
|--------|------|
| 资质 | 特种行业许可证、再生资源回收备案、中国黄金协会会员 |
| 持证 | 鉴定师持人社部黄金鉴定职业证书 |
| 设备 | XRF 无损测金仪 + 高精度电子天平，且**有计量校准记录** |
| 流程 | 称重/检测/计价全程在视线内，可录像 |
| 扣费 | 所有项目交易前公示、白纸黑字 |

**红线：凡是要把金子拿到后台隔间操作的，直接走人。**

### 第 4 步：到店操作清单

- [ ] 进店第一时间复核克重，与家里记录比对，偏差 >0.01g 立即提出
- [ ] 要求高温火烧或超声波清洗，**明确拒绝王水**
- [ ] 熔炼全程录像，人不离场
- [ ] 书面协议写明：旧金克重、纯度、工费单价、损耗上限、成品克重、交货日期
- [ ] 损耗写死上限（**争取 ≤2%**），超出部分由店家承担
- [ ] 确认工费是**按克**还是**按件**——小件按件可能更贵
- [ ] 问清有无模具费/设计费等额外项目
- [ ] 索要成品检测证书

## 五、50 克克重分配方案

古法金因实心锤揲、厚壁工艺，普遍比素金重。按 **48 克设计、留 2 克损耗缓冲**：

| 件 | 克重 | 说明 |
|----|------|------|
| 古法金手镯 | **22 g** | 主件，最见分量，建议做重点 |
| 古法金项链 | 11 g | |
| 古法金吊坠/长命锁 | 6 g | 可与项链配套 |
| 古法金戒指 | 5 g | |
| 古法金耳环 | 4 g | 一对 |
| **合计** | **48 g** | 余 2 克抵损耗 |

**弹性调整**：若 A 堆足金不足 48 克，优先保手镯克重（长辈最看重分量），压缩耳环和戒指。若最后差 3–5 克，现场按当日金价补（3 克约 3,000 元），金额可控。

## 六、时间线（倒推）

古法金工期长于素金，且 8–10 月是婚嫁旺季，工坊排单容易满。

| 时间 | 动作 |
|------|------|
| **8/21 – 8/31** | 分拣称重 → 检测定纯度 → 选店比价（至少问 3 家） |
| **9/1 – 9/5** | 定款、签书面协议、下单 |
| 9/5 – 9/25 | 制作期（手工錾刻 15–30 天 / 机制古法 7–15 天） |
| **9/25 前** | 取货验收，留 9 天缓冲 |
| 9/26 | 求婚 |
| **10/4** | 订婚（江西） |

> ⏰ **时间偏紧，建议本周内启动分拣和检测。** 9 月同时要办求婚和订婚，别把五金拖到 9 月中。

## 七、避坑速记

1. 回收**只认克重和纯度，不认工艺**——高工费在回收时归零，古法金回收价约为售价的 70–80%。别为工艺付过高溢价
2. 预算低于 2,500 元不建议做古法金；**30 克以上原料才划算**——你 50 克，条件很好
3. 警惕引导"足金换 K 金"（18K 含金量仅 75%），保值性差且多数不支持换回
4. 电话/微信报价远高于同行的，到店常以"纯度不够""行情突变"压价
5. 口头承诺一律无效，只认书面协议
