**社工岗性质：**

| 维度 | 说明 |
|------|------|
| 编制 | ❌ 编外合同制（社区专职工作者） |
| 薪资 | "四岗十八级"体系，约为事业编0.8-1.2倍 |
| 转编通道 | ✅ 有！累计5年+40岁以下优秀社区主干 → 定向考录公务员/事业编 |
| 笔试内容 | 二十大精神+居委会组织法+物业管理条例+公文写作+新罗区情等 |
| 门槛 | 🟢 大专以上，不限专业，持有社工证加3分 |
| 竞争 | 远低于事业编（门槛低但关注度低，3-10:1） |

**对曾周的价值判断：**

```
优势:
  ✅ 门槛极低（大专+不限专业），100%可报
  ✅ 每年稳定招录，新罗区岗位多
  ✅ 2024年国家政策加持，转编通道拓宽
  ✅ 有社工证可加分（曾周可以考，不难）
  ✅ 竞争小（3-10:1 vs 事业编30-80:1）

劣势:
  ⚠️ 不是编制，薪资低于正式事业编
  ⚠️ 转编需等5年+定向考试
  ⚠️ 笔试内容与综合基础知识完全不同，需额外准备
  ⚠️ 工作内容偏基层（邻里调解/社区服务/疫情防控等）

定位: 🟡 保底赛道
  如果事业编/国企/省考都没上岸，社工岗是进体制的最低门槛入口。
  先做社工→5年后转编，是一条"曲线救国"路线。
  但不建议作为主攻方向（投入产出比不如直接考事业编）。
```

## 四、关键趋势判断

### ✅ 好消息

1. **2026年事业单位艺术类岗反弹**：4个本科可报岗，为近年最多。可能意味着前几年缩编后的回调。
2. **融媒体中心成为稳定来源**：永定融媒体、龙岩融媒体连续出现，是视觉传达设计最对口的事业单位方向。
3. **国企每年至少1个设计岗**：宣传策划/企划岗位稳定出现，且看重作品集——曾周的强项。
4. **2年基层经历是隐藏优势**：曾周有7年社保，可报"2年基层工作经历"岗，这类岗竞争通常比普通岗低30-50%。

### ⚠️ 坏消息

1. **省考竞争5年翻3倍**：从17:1涨到51:1。
2. **教师编实质关闭**：新罗美术教师从8个降到1个。
3. **事业单位总量缓慢下降**：从765降到642。
4. **艺术类精准岗绝对量太少**：每年仅2-4个，必须同时准备不限专业岗作为保底。
