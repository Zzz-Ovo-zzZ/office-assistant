## 一、知识库 & 学习平台

### ⭐ SaDuck — 考公考编免费知识库

| 项目 | 说明 |
|------|------|
| 网址 | https://saduck.top |
| 费用 | 免费（部分功能需注册，年费约18元） |

> 建议设为浏览器首页，每天打开就能学。

## 三、AI 辅助工具

### ⭐ kaobuddy-pwa — 考搭子 KaoBuddy

| 项目 | 说明 |
|------|------|
| 仓库 | github.com/jin-zi-xuan/kaobuddy-pwa |
| Stars | ~301 |
| 平台 | 浏览器 PWA（Windows/Mac/手机） |
| 费用 | BYOK（自带 API Key，推荐 DeepSeek，便宜） |

**核心能力**：
- 📥 多格式导入：PDF/Word/手写照片/视频字幕 → AI 拆解知识点
- 📋 知识模块计划：自动识别可考知识点，排序难度和重要程度
- 🎯 模拟考：AI 出题 → 逐题批改 → 错题自动入错题本
- 🃏 学习卡片：概念卡/易错卡/考试卡/速背卡，滑动记忆
- 📅 每日计划：按剩余天数自动分配学习任务

**对曾周的价值**：
- 把零散的备考资料丢进去 → AI 拆成知识点 → 生成计划 → 模拟考
- 尤其适合**公基记忆类内容**（法律/政治/管理/公文）的快速消化
- 数据全存浏览器本地，隐私安全

> Windows 用户下载解压即用，双击 bat 文件启动。

## 四、备考方法论

### ⭐ fordot-team/gwy (D2G) — 程序员公考指南

| 项目 | 说明 |
|------|------|
| 仓库 | github.com/fordot-team/gwy |
| Stars | 23.3k ⭐ |
| 副标题 | 公务员从入门到上岸，最佳程序员公考实践教程 |

**核心内容**：

| 模块 | 内容 |
|------|------|
| **概述** | 公考100词、编制类型详解（行政编/事业编/参公/三支一扶等）、体制内真实情况 |
| **行测最佳实践** | 常识准备、瓶颈突破、学习自测方法 |
| **申论最佳实践** | 写作方法论、评分标准揭秘 |
