# 室内设计 · 局部翻新约束（柜体不动）

> 本文件补充通用方法论：当「原有柜体不能拆、只做软装与局部调整」时，怎么设计才既好看又落地。
> 适用于婚房翻新、旧房局部改造、出租房升级。

---

## 一、能改 / 不能改（先划清边界）

| 能改 | 不能改（或代价极高） |
|------|---------------------|
| 墙面颜色、壁纸、护墙板 | 柜体本体、柜门结构（可换门/换把手） |
| 窗帘、地毯、床品、抱枕 | 水电点位、地暖、墙内管线 |
| 灯具（吸顶/吊灯/壁灯/灯带） | 门窗洞口位置与尺寸 |
| 可移动家具（床、桌椅、边几） | 地面（除非整体翻新） |
| 装饰画、花艺、香薰、摆件 | 梁柱、承重墙 |

> 判断标准：**需要动电钻/水泥/涂料的，都算硬装**；本约束下只做"表面级 + 家具级"改动。

---

## 二、三种柜体颜色的配色支路（先测再配）

从照片取柜体主色，落进下面三支之一：

### 1. 柜体偏白 / 浅灰（最常见成品柜）
- 米杏打底 60%（墙面/床品），灰 30%（窗帘/地毯），黑 10%（灯具/把手/画框）。
- 最稳，几乎不挑风格；注意别用纯白墙，会显得柜子发灰。

### 2. 柜体偏暖木（橡木/樱桃木）
- 原木承接（同族），米杏打底，灰降到 20% 以下。
- **禁忌**：大面积冷灰会与暖木"发脏"，灰只做小面积（抱枕/单椅/灯具）。

### 3. 柜体偏深（胡桃/黑/深灰）
- 米杏提到 65% 提亮空间，黑只做线条，灰用浅灰（N8 以上）。
- 深柜 + 深墙 = 压抑；必须靠浅色床品/窗帘/地毯提亮。

## 三、旧柜"翻新"的四种低风险手段

| 手段 | 成本 | 效果 | 注意 |
|------|------|------|------|
| 换把手 | 低 | 立竿见影，风格切换最快 | 孔距要量，别买错规格 |
| 柜门贴膜/改色 | 中 | 换色不换结构 | 选哑光 PET/肤感膜，亮光显廉价 |
| 柜内加灯带 | 低 | 打开有仪式感 | 用充电式免布线，避免动电 |
| 柜顶/柜侧加装饰 | 低 | 弱化"成品柜"感 | 绿植/装饰画/挂毯，别堆满 |

## 四、局部翻新的五个常见翻车点

1. **只换墙色不改灯光**：墙变暖了，灯还是 6000K 冷白 → 全毁。灯光必须同步调。
2. **窗帘比例错**：帘杆太短、离顶太远 → 显矮。帘杆离顶 5–10cm，宽度超出窗洞 15–20cm。
3. **地毯太小**：1.6×2.3m 是卧室底线，床尾毯要压住床脚 1/3。
4. **装饰画挂太高**：画心离地 1450–1550mm（视线高度），别贴天花板。
5. **婚庆元素一次到位**：大红大金堆满 → 一年后必拆。改用可换季的织物与花艺。

## 五、验收前自检（在通用质量门之外）

- [ ] 所有新增家具的尺寸已与现有柜体/门洞核对，能进门、能转身。
- [ ] 新墙色与柜体色在**同一光源**下比对过（色卡贴柜门旁看）。
- [ ] 灯具色温统一（同一空间不混 3000K/4000K，书房除外）。
- [ ] 插座数量够用，没有明线横穿。
- [ ] 效果图与实际柜体位置一致（图不能"美化"掉柜子）。
