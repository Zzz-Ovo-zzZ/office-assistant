## 一、孟塞尔（Munsell）色彩系统

室内设计用色不能靠「大概蓝」或「浅米色」这种模糊描述，孟塞尔系统用「色相 明度/彩度」精确定位颜色。

```
孟塞尔标注：色相 明度/彩度
            5R 5/14 = 红色，中等明度，高彩度

色相 HUE（10 个主色相）
R(红) → YR(黄红) → Y(黄) → GY(黄绿) → G(绿)
→ BG(蓝绿) → B(蓝) → PB(紫蓝) → P(紫) → RP(红紫) → R

明度 VALUE（亮度 0-10）
0=纯黑，5=中灰，10=纯白

彩度 CHROMA（饱和度，0 到各色相上限）
0=中性灰，低彩度=柔和高级，高彩度=鲜艳强烈
```

**为什么室内设计用孟塞尔**：感知均匀（等步长看起来等差距）、油漆厂商（本杰明摩尔、宣伟等）通用、能精确下单、能预测颜色间如何互动。

## 二、色彩和谐计算

### 互补色（对面色）
`R↔BG、YR↔B、Y↔PB、GY↔P、G↔RP`，依次类推（对面 = 相差 5 个主色相）。

### 分裂互补色（互补色两侧的两个色）
主色相索引 `idx`，互补 = `(idx+5)%10`，分裂互补 = 互补两侧各一色。用于「一个主色 + 两个点缀色」时避免过于强烈。

### 明度对比度（WCAG 式）
明度 0-10 映射到亮度 `(v/10)^2.4`，对比度 = `(亮+0.05)/(暗+0.05)`。背景与前景明度差够大才清晰。

## 三、实用配色范例（客厅）

```
底色：10YR 8/2 暖白墙面 —— 高明度低彩度，后退感、显空间大
点缀1：5B 4/6 蓝绿沙发 —— 底色的互补方向，低明度抓视线
点缀2：5Y 7/4 金色抱枕 —— 与底色近似，中彩度添温暖
收边：N 9.5/ 近白 —— 中性最高明度，干净线条
地面：7.5YR 4/4 暖木色 —— 低明度压住空间
```

## 四、光与色的交互（最容易翻车的地方）

- **同色异谱（metamerism）**：一种光下颜色相同，另一种光下不同。所以**一定要在自家灯光下测试色样**。
- **朝北房间**：光偏冷，颜色会偏蓝，应选暖色调抵消。
- **朝南房间**：光偏暖，颜色显暖，可承受冷色。
- **LED 显色指数 CRI**：>90 才准，否则颜色失真。
- **易出错区域**：靠窗（日光与室内光混合）、暖色灯泡下（偏橙）、有色墙面旁（反射色）、高彩度色最受影响。

## 五、60-30-10 配色法则（落地口诀）

- **60% 主色**：墙面、地面、大件家具，中性打底。
- **30% 辅色**：窗帘、沙发、床品，协调统一。
- **10% 点缀色**：抱枕、装饰画、摆件，制造亮点。

**避坑**：全套同款同色 = 展厅感，缺少层次；点缀色太多 = 杂乱。先定 60% 中性底，再挑 1 个辅色 + 1 个点缀色贯穿全屋。
