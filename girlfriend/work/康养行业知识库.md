## 一、中国康养行业概况

### 1.1 人口老龄化基本面

| 指标 | 全国 | 福建省 | 龙岩市 |
|------|------|--------|--------|
| 60岁以上人口 | **3.1亿** | 780万 | **56.8万** |
| 老龄化率 | **22.0%** | 18.6% | **21.1%** |
| 65岁以上人口 | 2.2亿 | 541万 | 40.0万 |
| 失能/半失能老人 | 超4000万 | — | — |

> 🔑 龙岩老龄化率 21.1%，**高于全省平均 18.6%**，低于全国平均 22.0%，属于中度老龄化城市。南平(23.3%)、三明(22.1%)、宁德(21.8%)是福建最老的三个城市。

### 1.2 行业规模与趋势

| 指标 | 数据 |
|------|------|
| 银发经济规模 | 约 7 万亿元（占 GDP 6%） |
| 预计 2035 年 | 30 万亿元 |
| 全国养老机构 | 4.04 万家 |
| 全国医养结合机构 | 7,800+ 家，床位 200 万张 |
| 长护险参保人数 | 1.8 亿人 |
| 养老护理员缺口 | 超 400 万 |

### 1.3 医养结合主流模式

```
传统模式（正在被淘汰）：
  医院 ←→ 养老院 （各管一段，割裂）

新模式（医康护养一体化）：
  预防 → 治疗 → 康复 → 长期照护 → 安宁疗护
  └────────────── 全周期连续服务 ──────────────┘
```

**六维融合趋势：** 医、养、康、文、旅、金 深度融合

**关键趋势判断：**
- 从"养老 1.0"（生存保障）→ "享老 2.0"（品质生活）
- 社区嵌入式养老是未来方向（"不离家不离社区"）
- 险资大举入场（泰康、太平、太保等）
- AI + 智慧养老成为标配

### 2.2 新罗区街道/社区详解（业务核心区域）

新罗区 = **10 个街道 + 10 个镇**，是万龄康养的核心服务半径。

#### 10 个街道及核心社区

| 街道 | 核心社区/村 | 老龄化特征 |
|------|-----------|-----------|
| **东城** | 东风社区(高龄/残疾/困难多)、东门、松涛、北龙 | 老城区，老年人口密集 |
| **南城** | 溪南、莲东、新陂(有养老照料中心)、黉门前 | 老龄化突出，新陂有智能养老试点 |
| **西城** | 西安、莲新(老旧小区改造)、西平、莲花 | 老旧小区多，老年租户多 |
| **中城** | **北门**(全国示范性老年友好型社区)、凤凰、北关 | **北门社区 60+占比 15.7%，获得国家级荣誉** |
| **西陂** | 西山、大洋、小洋、排头、张白土 | 城乡结合部，人口增长快 |
| **曹溪** | **天马社区**(全国示范)、曹溪村、月山、浮蔡 | **天马社区 60+占 12.84%，医养社院融合** |
| **东肖** | 溪连、菜园、邓厝、联邦 | 奇迈片区规划健康养老项目 |

| **铁山** | 洋头、溪西、外洋 | 工业区，人口分散 |
| **北城** | （社区信息较少） | 新设街道 |

红坊、适中、雁石、白沙、万安、大池、小池、江山、岩山、苏坂

### 4.5 竞品关键洞察

1. **同心圆是最大对手**：五星级 + 智慧养老 + 公建民营 + 品牌沉淀
2. **连锁品牌已入场**：普亲养老(全国连锁)、龙人伍心家园(连锁)
3. **万龄的差异化优势**：医养融合（中医院分院在院内）+ 全新设施 + 政府重点扶持 + 25,000㎡规模
4. **万龄的劣势**：2026年1月刚开业，品牌知名度低，入住率才起步（约50人/137备案床位 ≈ 36%，但对比500张规划床位仅10%）

## 五、万龄康养中心（她的公司）

### 5.1 基本信息

| 项目 | 详情 |
|------|------|
| 全称 | 龙岩市万龄养老服务有限公司（前身：万龄健康投资有限公司） |
| 位置 | 新罗区北部新城（未来城/厦龙合作区） |
| 规模 | 总建筑面积约 25,000㎡，实际使用面积近 30,000㎡ |
| 投资 | 约 1 亿元 |
| 床位 | 规划 500 张（含一级综合医院床位 50 张） |
| 开业 | 2024年9月签约，2025年4月试运营，**2026年1月11日正式开业** |
| 运营状态 | 南楼 1-4 层已投用，备案床位 137 张，入住约 50 人 |

### 5.2 核心优势（对外宣传的卖点）

1. **医养融合**：内设龙岩市中医院北部新城分院（一级综合医院），床边诊疗、中医理疗
2. **服务特色六大项**：专业医护 24h、医养绿色通道、智能监护、文娱活动、家庭喘息短租、疗愈花园
3. **房型多样**：单人雅居、双人馨居、家庭组团、VIP 颐养套房
4. **定位**：旅居康养 + 高端康养 + 居家上门 + 大健康养老 四位一体
5. **政府背书**：新罗区重点民生项目，苏坂镇专项服务专班
6. **保险合作**：太平人寿福建分公司已考察，探讨合作

### 5.3 业务关键信息

- 她的工作：外勤跑业务，对接医院医生及护工
- 主要目标客户：术后康复（骨科/神内）、失能照护需求老人
- 地理位置偏：北部新城/未来城是新开发区域，离市中心有一定距离
- 中高端定位：价格不是最低的，需要靠服务品质说服客户

### 6.3 药店渠道打法

- 先谈康佰家或海华的**区域经理**（不是单个门店）
- 单个社区药店通常 500-2000 慢病会员
- 切入场景：药店慢病日、会员活动
- 核心卖点：帮药店增加会员忠诚度 + 合作费用
