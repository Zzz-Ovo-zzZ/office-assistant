# 室内设计 · 空间规划与人体工学

> 本文件为室内设计提供空间规划、动线、家具间隙的数值标准，供 Claude 判断家具「放不放得下、走不走得通」。
> 覆盖：人体工学、动线宽度、家具间隙、比例系统。
> 来源：interior-design-expert skill（Apache-2.0）的 space-planning reference，已本地化（中国户型以 mm 为主）。

---

## 一、动线宽度（人能不能顺畅走）

| 类型 | 宽度 | 场景 |
|------|------|------|
| 主通道 | 900–1200mm | 主过道、客厅主要路径、厨房工作三角 |
| 次通道 | 600–900mm | 家具之间、卧室床边、书房路径 |
| 极限挤压点 | ≥450mm | 墙与家具之间、狭窄处（不能作为常用通道） |

**铁律**：先画动线，再摆家具。家具把主通道挤到 <900mm，房间就会显挤。

---

## 二、家具间隙（关键距离速查）

| 关系 | 建议距离 |
|------|---------|
| 沙发 ↔ 茶几 | 450–500mm |
| 餐桌椅后退空间 | ≥900mm |
| 床侧通行 | ≥600mm（单人侧可 500mm） |
| 书桌椅活动区 | 900×900mm |
| 衣柜前 | ≥750mm（平开门需更多） |
| 床头柜 ↔ 床 | 贴放或 ≤50mm |

## 三、人体工学基准（中国成人）

| 项目 | 数值 |
|------|------|
| 坐姿椅面高 | 430–530mm |
| 坐姿眼高（离地） | ≈1180mm |
| 膝盖下方净空 | ≥640mm |
| 大腿下方净空 | ≥190mm |

## 四、比例系统（让布局「顺眼」）

- **黄金比例 φ=1.618**：房间长宽比、家具组合比例、挂画位置，用了不一定神奇，但常更耐看。
- **根矩形**：√2(1:1.414)、√3(1:1.732)、双正方形(1:2) —— 常见于地毯、户型比例。
- **家具组合比例**：茶几长度 ≈ 沙发长度的 0.6（约 φ⁻¹）；边几 ≈ 沙发长度的 0.25。
- **实用判断**：房间 4m×6m = 1:1.5（介于 √2 与 φ 之间），比例舒服。

---

## 五、布局校验清单（质量门，设计完逐条自检）

- [ ] 主通道 ≥900mm，次通道 ≥600mm，无家具挡死角落。
- [ ] 茶几长度 = 沙发长度的 40–50%。
- [ ] 地毯延伸到前排家具腿下方（不是孤零零一块）。
- [ ] 视觉重量均衡：任何单一象限不要堆 >60% 的视觉重量（深色、大件家具）。
- [ ] 每个功能都有专属区域 + 对应照明/收纳。
- [ ] 插座位够用，没有电线横穿走道。

---

## 六、失败模式（常见翻车点）

1. **尺寸失配**：家具间隙 <450mm，或大沙发挡住 50% 以上动线 → 房间显挤。**先量动线再定家具尺寸**。
2. **单一顶灯**：只有一盏中央灯 → 脸上全是阴影、看书费劲。**分层布光**。
3. **全套同款**：所有家具同风格同色 → 展厅感、没个性。**60-30-10**。
4. **颜色不测**：只看小色卡或屏幕 → 刷完完全两样。**上墙试 60×60cm 大样 48 小时**。
5. **盲目跟风**：不管房间条件硬套网红风 → 四不像。**先分析房间比例、采光、硬装**。
