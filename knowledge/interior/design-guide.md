# 室内设计 · 方法论总纲

> 本文件为室内软装设计的整体工作方法，供 Claude 在做设计时遵循「先分析、后决策、再校验」的流程。
> 覆盖：执行流程、色彩决策流程、灯光层级矩阵、失败模式、质量验收门、60-30-10 与预算分配。
> 来源：interior-vibing + interior-design-expert（Apache-2.0）综合，已本地化。

---

## 一、执行流程（软装设计五步）

```
STEP 1 读图分析：读现场照/户型图，输出「房间分析 12 项」（见下）
STEP 2 对齐需求：明确风格、预算、功能（书房/主卧/餐厅各自用途）
STEP 3 定方案：套用风格决策树 + 色彩决策流程，定配色/家具/灯光
STEP 4 出可视化：生图（效果图）+ 平面布局图
STEP 5 校验交付：过「质量验收门」，输出家具清单 + 采购建议
```

---

## 二、房间分析 12 项（读图必做）

1. 房间类型与尺寸（用家具当比例尺估算）
2. 地板（材质、色调、品相）
3. 墙面（颜色、质感、造型）
4. 自然采光（窗数、朝向、质量）
5. 人工照明（灯具类型、是否分层）
6. 固定元素（不能改的：柜体、飘窗、垭口）
7. 现有家具（逐件：风格/颜色/品相，保留或替换）
8. 建筑风格与年代
9. 空间流线（入口、主视线、焦点墙、死角、最佳拍照角度）
10. 最佳资产（这个房间最好的设计点）
11. 最大问题（最该解决的痛点）
12. 缺失必需品（明显缺但还没有的）

> 描述要精确：不说「木地板」，说「中暖色白橡、约 5 寸宽板、哑光、门口轻微磨损」。

---

## 三、色彩决策流程

1. **看采光**：朝北选暖色调（别用冷灰）；朝南可承受冷色；朝东/西要分时段试。
2. **看功能**：睡眠/放松 → 低彩度暖色；工作/专注 → 中彩度中性；娱乐 → 可高彩度。
3. **看空间感**：要显大 → 高明度(7-9)冷色；要温馨 → 中明度(4-6)暖色。
4. **落地**：60-30-10（60% 主色打底、30% 辅色、10% 点缀）。

## 四、灯光层级矩阵（按房间定优先级）

| 房间 | 灯光优先级 |
|------|-----------|
| 卧室 | 环境光(柔光) → 任务光(床头) → 重点光(氛围) |
| 书房 | 任务光(台灯) → 环境光(顶灯) → 重点光 |
| 餐厅 | 重点光(吊灯打餐桌) → 环境光 → 任务光 |
| 客厅 | 环境光 → 重点光(落地灯) → 任务光(阅读灯) |

**预算约束**：高预算三层全上+智能；中预算环境+任务；低预算优先任务光 + 落地灯补充。

## 五、失败模式（设计前先避坑）

1. **盲目跟风**：不看房间条件硬套网红风 → 四不像。先分析比例/采光/硬装。
2. **单一顶灯**：只有一盏中央灯 → 阴影重、无氛围。分层布光。
3. **尺寸失配**：间隙 <450mm、大沙发堵死动线 → 显挤。先画动线再定尺寸。
4. **颜色不测**：只看小色卡 → 刷完两样。上墙 60×60cm 大样试 48 小时。
5. **全套同款**：全屋一个系列 → 展厅感。60-30-10 破局。

## 六、质量验收门（方案交付前逐条过）

- [ ] 动线：主通道 ≥900mm、次通道 ≥600mm，无家具挡死角。
- [ ] 灯光：至少 2 层（环境+任务），可独立控制。
- [ ] 比例：茶几 = 沙发长 40-50%，地毯压在前排家具腿下。
- [ ] 视觉重量：单象限视觉重量 <60%。
- [ ] 功能分区：每个活动有专属区 + 对应照明/收纳。
- [ ] 预算分配：家具 60% / 灯光 25% / 配饰 15%。
- [ ] 风格一致：60-30-10 已应用。
- [ ] 尺寸落地：所有家具尺寸符合国标 + 房间实测。

---

## 七、采购优先级（先买什么）

1. **刚需大件**：床架+床垫、书桌、餐桌椅（决定空间骨架）。
2. **功能收纳**：衣柜、书柜、餐边柜（决定「乱不乱」）。
3. **灯光**：主灯 + 床头/台灯 + 餐桌吊灯（决定氛围）。
4. **软装配饰**：窗帘、地毯、装饰画、绿植（最后点睛）。

> 原则：先定尺寸再买（量好门洞/电梯/房间）；床垫比床架重要；灯光分层比一盏大主灯高级。
