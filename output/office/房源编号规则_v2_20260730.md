# 房源数字编号规则 v2

> 创建日期：2026-07-30 | 适用：天宇 / 惠和 及后续项目 | 基于历史编号经验整理

---

## 一、编号结构

```
数字编号 = 项目编号(2位补零) + 楼栋编号(2位补零) + 房源编号(4位补零)
```

**固定总长 8 位**。

| 段 | 位数 | 说明 |
|------|------|------|
| 项目编号 | 2位 | 01~99，不足2位左侧补零 |
| 楼栋编号 | 2位 | 01~99，不足2位左侧补零 |
| 房源编号 | 4位 | 0001~9999，不足4位左侧补零 |

**示例**：`01020101` = 项目01(梅林片区) + 楼栋02(梅林综合楼B栋) + 房源0101

## 二、房源编号核心规则（4位补零）

### 规则1：普通数字
直接取房间号，4位补零。

| 房源名称 | 房源编号 |
|----------|:--------:|
| 101 | `0101` |
| 303 | `0303` |
| 1003 | `1003` |

### 规则2：A/B/C栋（千位区分）

| 栋 | 千位 | 示例 |
|----|:----:|------|
| A栋 | 0 | `A栋101` → `0101` |
| B栋 | 1 | `B栋101` → `1101` |
| C栋 | 2 | `C-605` → `2605` |

### 规则3：同栋多套（千位区分同名）

同一楼栋内同一房间号有多个时，千位递增。

| 房源名称 | 房源编号 |
|----------|:--------:|
| 201-1（第1套） | `0201` |
| 201-2（第2套） | `1201` |
| 201-3（第3套） | `2201` |

### 规则4：方向标识（东/南/西/北/中）

直接取数字，不加千位区分（方向本身已经是区分）。

| 房源名称 | 房源编号 |
|----------|:--------:|
| 东侧1层 | `0101` |
| 南侧2层 | `0102` |
| 北侧三层 | `0301` |
| 东侧四层401 | `0401` |

### 规则5：多层/多号（取首层号）

| 房源名称 | 房源编号 |
|----------|:--------:|
| 东侧一层1-3层 | `0101` |
| 4-7层 | `0401` |
| 底层1-3号 | `0101` |

### 规则6：楼层+方位组合

取楼层号×100 + 首房间号。

| 房源名称 | 房源编号 |
|----------|:--------:|
| 三层北侧 | `0301` |
| 三层南侧 | `0302` |
| 五层北侧-1 | `0501` |
| 五层北侧-2 | `1501`（第2套，千位=1） |

### 规则7：门牌号

直接取门牌号数字部分。

| 房源名称 | 房源编号 |
|----------|:--------:|
| 解放北路28号 | `0028` |
| 解放北路36号 | `0036` |

## 三、千位含义速查

| 千位 | 含义 |
|:----:|------|
| 0 | A栋 / 东侧 / 北侧 / 第1套（默认） |
| 1 | B栋 / 南侧 / 西侧 / 第2套 |
| 2 | C栋 / 第3套 |
| 3+ | D栋 / 第4套及以上 |

## 四、项目编号 & 楼栋编号

- **项目编号**：按片区维护顺序排列，2位补零（01~99）
- **楼栋编号**：按项目内楼栋顺序排列，2位补零（01~99）
- 编号对照表随项目增减更新

### 当前项目范围

| 项目 | 项目数 | 楼栋数 | 房源数 |
|------|:------:|:------:|:------:|
| 天宇 | 1~46 | 1~19 | 707 |
| 惠和 | 1~29 | 1~22 | 681 |

## 五、特殊情形处理

### 5.1 整栋建筑（资产 = 楼栋本身）

资产名称等于或直接对应整个楼栋，无法再细分到具体房源。

→ **房源编号统一填 `0101`**（表示该楼栋整体作为一个房源）

| 资产名称 | 房源编号 | 说明 |
|----------|:--------:|------|
| 龙达厂房一期1# | `0101` | 整栋厂房 |
| 创业园B幢 | `0101` | 整栋办公楼 |
| 教学楼 | `0101` | 整栋教学楼 |
| 东宝山二期宿舍 | `0101` | 整栋宿舍 |

### 5.2 土地 / 空地 / 杆线 / 道路

地块、空地、路灯杆线等非建筑物资产，也需纳入编号管理。

→ **房源编号用 `9xxx` 段**，9001 起按资产出现顺序递增（同一楼栋内）

| 资产名称 | 房源编号 | 说明 |
|----------|:--------:|------|
| 创业园E幢一楼停车坪空地 | `9001` | 空地 |
| 园十路绿化带 | `9002` | 绿化带 |
| 青竹路路边空地 | `9003` | 空地 |
| 龙州工业园民园路68根灯杆 | `9004` | 杆线 |

### 5.3 基站 / 屋面 / 屋顶 / 天面

楼顶设施，不属于常规楼层。

→ **房源编号用 `99xx` 段**

| 资产名称 | 房源编号 | 说明 |
|----------|:--------:|------|
| 屋顶基站 | `9901` | 基站 |
| 屋面基站 | `9902` | 基站 |
| 楼顶天面基站 | `9903` | 基站 |
| 屋面（租赁面积） | `9904` | 屋面 |

### 5.4 地下室 / 负层

→ **楼层×100 + 1，千位保持原规**（负层暂不做特殊编码）

| 资产名称 | 房源编号 | 说明 |
|----------|:--------:|------|
| 地下室 | `0001` | 无具体楼层信息 |
| 半地下停车库 | `0001` | 同地下室 |
| 负一层车库 | `0101` | 取绝对值 -1→1 |

### 5.5 其他特殊情形

| 情形 | 处理方式 |
|------|----------|
| 无房间号的（如"一层"整体） | 取 `0101` |
| 设备房 | 按所在楼层取号，如一层设备房→`0101` |
| 门卫 | 按所在楼层取号，无楼层取 `0101` |
| 无数字标识的（如"食堂""展厅"） | 取 `0101` |
