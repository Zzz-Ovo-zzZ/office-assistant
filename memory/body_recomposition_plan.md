# 身体重塑计划 v2

**创建日期**: 2026-07-04 | **最后更新**: 2026-07-05

## 用户基础数据

- 身高 176cm，体重 82kg，男性，30岁
- BMI 26.5，估测体脂率 ~20-22%
- 有健身痕迹，瘦体重约 64-66kg
- BMR ~1790 kcal，TDEE ~2770 kcal
- 体型倾向：内胚型

### v2 关键调整

1. **蛋白粉 1勺 → 3.5勺**：早餐1勺 + 加餐2.5勺，弥补午餐蛋白不可控
2. **早餐升级**：牛油果半个 + 原味坚果10g + 无糖酸奶200g，营养密度提升
3. **牛奶 500ml → 250ml+250ml**：早餐和加餐各一份，分散摄入
4. **香蕉固定2根**：训练前后各一根，功能性碳水
5. **坚果从20g → 10g**：控制脂肪总量
6. **午餐涮水保留**：核心控油手段不变

### 热量缺口评估

```
TDEE ≈ 2,770 kcal
摄入 ≈ 2,460 kcal
缺口 ≈ 310 kcal/天

每周脂肪减少 ≈ 310 × 7 / 7,700 ≈ 0.28 kg
每月脂肪减少 ≈ 1.1 kg（纯脂肪）
```

> 这是一个**温和缺口**，介于重塑（-170）和原减脂方案（-470）之间。优势是：饥饿感低、训练质量有保障、可持续性好。代价是进度慢一点——但减脂是马拉松，急不得。

### 训练

- **力量**：每周 4 次（上下肢分化），强度不能降
- **有氧**：每周 2-3 次，快走 40 分钟（心率 142-154）或 HIIT 15 分钟
- **NEAT**：每日步数 ≥ 10,000
- **核心动作**：深蹲、硬拉、卧推、划船、推举

### 周期策略（可选）

保持 2,460 kcal 持续运行即可。因为缺口本身不大（-310），代谢适应风险低。如果 4-6 周后体重不降，再考虑降到 2,300。

### 追踪

| 指标 | 频率 | 方法 |
|------|------|------|
| 体重 | 每天早晨空腹 | 看 7 日均值，不纠结单日 |
| 腰围 | 每 2 周 | 肚脐水平位 |
| 力量 | 每 4 周 | 三大项至少维持 |
| 进度照 | 每 4 周 | 同光线同角度 |

### 红灯信号

- 连续 3 周体重不降 → 检查是否漏记油脂/零食，考虑降回 2,300
- 力量明显下降（>10%）→ 碳水提到 270g
- 整天疲劳、睡眠差 → 回 2,600 维持一周

### 备选方案

- **身体重塑**（2,600 kcal / 蛋白 200g / 碳水 290g / 脂肪 70g）：减脂达标后切换
- **激进减脂**（2,300 kcal / 蛋白 200g / 碳水 200g / 脂肪 65g）：需要加速时切换

**Why:** 用户在 v1 减脂方案基础上做了两件事——早餐营养升级（牛油果/坚果/酸奶）和午餐蛋白松绑（牛肉不可控）。代价是蛋白从 190g 降到 165g。解决方案：蛋白粉从 2 勺加到 3.5 勺，蛋白回升到 199g，同时热量从 2,300 升到 2,460——缺口从激进（-470）变成温和（-310），更适合长期执行。

**How to apply:** 早餐照表执行（固定搭配，不用犹豫）。午餐正常吃+涮水，不用纠结牛肉有没有。加餐蛋白粉 2.5 勺是基准，根据当天午餐肉量微调（肉少多补、肉多少补）。晚餐固定。每 2 周测腰围，每月拍进度照。
