## 三、v2 核心调整

```
v1 的问题：
  早餐只有牛奶+燕麦+鸡蛋 → 营养密度一般
  午餐牛肉不可控 → 蛋白波动大
  蛋白粉只有 2 勺 → 蛋白兜不住底

v2 的解决：
  早餐 +牛油果 +坚果 +酸奶 → 优质脂肪 + 益生菌 + 微量营养素
  蛋白粉 2勺 → 3.5勺 → 蛋白中轴从 48g → 84g
  午餐松绑 → 有肉没肉都不用纠结，蛋白粉已兜底
  坚果减量 → 20g → 10g，控制脂肪
```

## 七、蛋白双档：午餐不可控的应对策略

这是 v2 的核心设计——**午餐蛋白不可控 → 蛋白粉做调节器**。

```
固定蛋白（每天雷打不动）：
  早餐 62.5g + 晚餐 31g + 加餐(除蛋白粉) 10g = 103.5g

蛋白粉中轴（3.5勺）：
  +84g 蛋白

午餐浮动：
  有肉 +35g → 总计 222g → 实际吸收 ~199g（消化损耗约10%）
  没肉 +14g → 总计 202g → 实际吸收 ~178g
```

| 场景 | 摄入蛋白 | 每 kg 体重 | 是否安全 |
|------|---------|-----------|---------|
| 🥩 有肉 | ~199g | 2.43g/kg | ✅ 理想 |
| 🥬 没肉 | ~178g | 2.17g/kg | ✅ 安全 |
| 🍖 肉多(>120g) | ~210g | 2.56g/kg | ✅ 更好 |

> 🔑 **操作口诀**：午餐肉多 → 加餐蛋白粉减到 2 勺；午餐没肉 → 加餐蛋白粉加到 3 勺。总量围绕 3.5 勺波动。
>
> 蛋白粉是你这个方案里的**战略缓冲**——让你不再为"今天食堂有没有牛肉"焦虑。

## 十、周期与预期

### 为什么不需要维持周？

v1（-470 缺口）→ 每 4 周设维持周，防止代谢适应。  
v2（-310 缺口）→ 缺口温和，身体不会触发明显的代谢下调，可以持续跑。

如果后期想加速，可以切到 v1 方案跑 4 周再回来——但 v2 本身就可以一直用到达标。

### 进度预期

```
每日缺口 310 kcal × 7 = 每周 2,170 kcal
每周纯脂肪减少 ≈ 0.28 kg
```

| 时间 | 预计体重 | 说明 |
|------|---------|------|
| 起点 | 82.0 kg | — |
| 第 4 周 | 80.8 kg | 前两周含水下降偏快 |
| 第 8 周 | 79.5 kg | 稳定减脂 |
| 第 12 周 | **78.3 kg** | -3.7 kg，体脂率约 19% |
| 第 16 周 | **77.2 kg** | -4.8 kg，体脂率约 18% |

> 这是**保守估计**。如果严格执行 + 训练到位，进度会更快。关键是别着急——12 周减 3.7kg 纯脂肪，穿衣服的变化比你想象的明显。

## 十二、注意事项

1. **涮水不能停** — 这是控油的王牌手段，午餐的灵魂
2. **蛋白粉是预算，不是负担** — 3.5 勺是为了弥补午餐的不确定性，不是在浪费钱
3. **牛油果 + 坚果值得** — 单不饱和脂肪支持睾酮水平，减脂期尤其重要
4. **香蕉不要砍** — 2 根香蕉 ≈ 训练燃料 + 糖原回补，砍了训练质量会明显下降
5. **练腿日可以多吃** — 晚餐土豆多半个（+30g），不差这 25 kcal
6. **睡眠 7-8 小时** — 减脂效果一半在厨房，一半在卧室
7. **到达 76-78 kg 后** — 切换到身体重塑方案（2,600 kcal），开始增肌期
