# 室内设计 · 家具软装选购避坑

> 本文件为家具软装选购的实战经验，供 Claude 给出「先别怎么做、再怎么做」的落地建议。
> 来源：zhuangxiu-skills（西安装修课堂）家具软装选购专题精华，已本地化。

---

## 一、核心原则（先记住这 5 条）

1. **先定尺寸再买**：量好门洞、电梯、房间，别等沙发进不了门才傻眼。
2. **床垫比床架更重要**：支撑和透气优先，别被外观带偏。
3. **窗帘看遮光与垂感**：卧室要遮光，客厅要垂顺，布料和轨道比花型关键。
4. **软装少而精**：一个空间一个主色调，装饰画和摆件宁少勿杂。
5. **灯光分层才高级**：基础照明 + 重点照明 + 氛围光，比一盏大主灯舒服太多。

---

## 二、分项选购要点

### 沙发
- 座深 480–600mm（身高较高选深座）；坐感要亲自试（硬支撑 > 软塌）。
- 面料：有宠物/小孩选科技布或耐磨布艺；客厅常用选棉麻透气。
- 尺寸：先量客厅墙长，沙发占墙 2/3 为宜，留出走道 ≥900mm。

### 床 + 床垫
- 床架看承重与静音（排骨架间距 <5cm 才稳）；实木床看榫卯。
- 床垫：硬床垫（棕垫/偏硬弹簧）适合腰不好；独立袋装弹簧 + 乳胶/记忆棉适合两人睡（不互相影响）。
- 床垫一定要躺试 ≥10 分钟，别网购盲买太软/太硬的。

### 窗帘
- 卧室：遮光率 ≥90%，选绒布/雪尼尔/遮光布 + 里衬。
- 客厅：垂顺为主，选棉麻/高精密，纱帘 + 布帘双层。
- 轨道：静音罗马杆或滑轨；窗帘盒遮光最好。

### 地毯
- 尺寸：主地毯要压到沙发/床的前腿下（不是孤岛）。
- 材质：羊毛显质感但贵、难打理；丙纶/涤纶好清洗、性价比高；有小孩选短毛易清洁。

### 书桌 / 书房家具
- 书桌高 700–760mm，配椅后座面与桌面高差 250–320mm。
- 桌面深 ≥500mm 才放得下显示器+键盘；靠墙放时留出桌下容膝 ≥580mm。
- 书柜深度 300mm（普通书），大开本/收纳箱需 350–400mm。

### 餐桌 / 餐厅家具
- 4 人桌 1200–1400×800mm；6 人 1600–1800mm；圆桌直径 1.2m 坐 4-6 人。
- 餐椅后退需 ≥900mm 空间；餐边柜深 350–400mm，留出走道。

## 三、避坑清单（买前自查）

- [ ] 量过门洞宽度、电梯尺寸、房间墙面长度了吗？
- [ ] 大件（沙发/床/衣柜）能否进得去、摆得下、留出走道？
- [ ] 「实木」是原木还是贴皮/指接？（问清材质，别被「实木」二字带偏）
- [ ] 板材柜体是什么板？（潮湿区多层板、承重颗粒板/欧松板）
- [ ] 环保等级有没有检测报告？（看胶水种类，E0/ENF 只是单件送检）
- [ ] 床垫躺试过吗？窗帘遮光率够吗？灯光分层了吗？
- [ ] 网购大件是否包入户、包安装、可退换？

---

## 四、选购顺序（钱花在刀刃上）

1. 先买**刚需大件**：床+床垫、书桌、餐桌椅（骨架）。
2. 再买**收纳**：衣柜、书柜、餐边柜（决定乱不乱）。
3. 再配**灯光**：主灯 + 床头/台灯 + 餐桌吊灯（决定氛围）。
4. 最后**软装**：窗帘、地毯、装饰画、绿植（点睛）。

> 预算分配参照：家具 60% / 灯光 25% / 配饰 15%。
