# 室内设计 · 灯光设计

> 本文件为室内设计提供灯光设计的底层原理与数值标准，供 Claude 给出专业灯光建议。
> 覆盖：IES 照度标准、四层布光法、色温编程、昼夜节律。
> 来源：interior-design-expert skill（Apache-2.0）的 lighting-design reference，已本地化。

## 一、照度标准（IES 推荐，单位 lux）

| 空间 | 照度建议 |
|------|---------|
| 客厅一般活动 | 150–300 lux |
| 阅读 / 精细工作 | 300–500 lux |
| 厨房台面 | 300–750 lux |
| 卫生间镜前 | 300–500 lux（垂直照面） |
| 卧室一般 | 50–150 lux |
| 过道 | 50–100 lux |
| 餐厅（氛围） | 100–200 lux |

- **垂直照度**：墙面装饰画 200–500 lux（常高于环境光）；镜前灯应从正面打，不要只从头顶。
- **均匀度**：最亮/最暗比 <3:1 才舒适（避免死角和刺眼点）。

## 二、四层布光法（告别单一顶灯）

**第一层 · 环境光（基础照明）**
- 提供整体照明，占总量 60–70%。
- 来源：筒灯、吸顶灯、灯带、吊灯。
- 计算：`流明 = 面积(m²) × 照度(lux) ÷ CU ÷ MF`（CU 利用系数约 0.5–0.8，MF 维护系数约 0.8）。

**第二层 · 任务光（功能照明）**
- 补充特定活动的照明，比环境光亮 2–3 倍。
- 来源：书桌台灯、岛台上方吊灯、橱柜下灯。
- 要点：避免在作业面留下阴影。

**第三层 · 重点光（装饰照明）**
- 制造层次与戏剧感，比环境光亮 3–5 倍。
- 来源：轨道灯、射灯、画灯、上照灯。
- 光束角：窄 10–15°（聚焦画作）、中 25–40°（一般重点）、宽 50–60°（洗墙）。

**第四层 · 自然光**
- 免费健康，但按最差情况设计（阴天冬季）。
- 控制眩光：窗帘、百叶、柔纱。
- 采光系数目标 ≥2–5%。

## 三、色温编程（各空间各时段，单位 K）

| 空间 | 白天 | 傍晚 | 夜间 |
|------|------|------|------|
| 客厅 | 4000 | 2700 | 2200 |
| 卧室 | 3500 | 2700 | 2200 |
| 厨房 | 4000 | 3000 | 2700 |
| 卫生间 | 4000 | 3000 | 2400 |
| 书房/办公 | 5000 | 4000 | 3000 |
| 餐厅 | 3000 | 2700 | 2400 |

**昼夜节律**：早晨 5000–6500K 提神，白天 4000–5000K 高效，傍晚 2700–3000K 放松，夜间 2200–2700K 助眠。卧室晚 8 点后、睡前用卫生间、夜间过道避免冷蓝光（<3000K 才合适）。

## 四、卧室 / 书房 / 餐厅速配（对应你的三个房间）

- **卧室**：环境光（柔光吸顶/灯带）+ 任务光（床头壁灯或台灯，2700K）+ 重点光（可选），**不要只装一个吸顶灯**。床头灯下沿约离床面 60–80cm。
- **书房**：**任务光优先**——书桌台灯 4000–5000K、照度 300–500 lux、避免屏幕反光（灯从侧面打）；环境光辅助；避免只有一盏吊灯直射。
- **餐厅**：重点在餐桌——吊灯离桌面 70–80cm、色温 2700–3000K 暖光让食物好看、照亮桌面直径比餐桌窄 30cm 左右即可。
