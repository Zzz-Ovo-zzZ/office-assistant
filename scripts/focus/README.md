# 🚀 前进吧zzz（置顶监督 + 番茄钟 + 游戏化）

一个帮你对抗低自制力的悬浮番茄钟，**零第三方依赖**（托盘功能可选依赖 pystray+Pillow），双击即可运行。

## 运行

```bash
python scripts/focus/pomodoro.py
# 或双击
scripts/focus/start.bat
```

## 功能

| 功能 | 说明 |
|------|------|
| 窗口置顶 | 默认始终悬浮在最上层，可右上角开关 |
| 任务计划 | 添加任务 + 预计番茄数，完成番茄自动累计进度 |
| 番茄钟 | 25 分钟专注 / 5 分钟短休 / 15 分钟长休（每 4 个一轮），时长可自定义 |
| 迷你专注模式 | 开始专注时窗口自动缩小，只保留计时环 + 鼓励语 + 暂停/返回，减少干扰 |
| 音效 | 完成番茄/任务时播放**合成的欢快铃声**（自动生成 WAV，无需音频文件） |
| 彩带特效 | 完成时撒彩带粒子 + 中央弹出成就文字 |
| 鼓励语 | 大量正向文案，完成/休息/开始时随机出现 |
| 游戏化 | XP、等级称号、连击天数、今日番茄与专注时长 |
| 自定义时长 | ⚙ 设置面板：专注/短休/长休时长、长休间隔 |
| 系统托盘 | 关闭窗口最小化到托盘，托盘图标带菜单（显示/开始暂停/退出） |
| 任务栏进度 | 任务栏按钮实时显示当前番茄进度（绿色进行中 / 黄色暂停） |
| 专注热力图 | 📊 统计面板：近 14 天专注柱状热力图 + 累计/连击汇总 |
| 开机自启 | ⚙ 设置面板勾选，写入注册表 Run 键，开机静默启动 |

## 快捷键

- `空格`：开始 / 暂停

## 系统托盘（可选依赖）

托盘功能依赖 `pystray` + `Pillow`，未安装时自动降级（关闭窗口直接退出）：

```bash
pip install pystray pillow
```

## 数据

任务与统计自动保存到 `scripts/focus/focus_data.json`，重启不丢失。
