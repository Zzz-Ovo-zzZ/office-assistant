# 室内设计 · 风格指南

> 本文件为室内设计提供主流风格的 DNA 拆解与混搭规则，供 Claude 判断「用户该选什么风格、怎么落地」。
> 覆盖：现代简约、原木日式、奶油风、北欧、轻奢、中古风，及混搭法则。
> 来源：interior-design-expert skill（Apache-2.0）的 style-guide + zhuangxiu-skills 风格实战，已本地化（中国户型、主流价位）。

---

## 一、现代简约

- **特征**：线条干净利落、白灰木为主、去繁就简、耐看好搭配。
- **材质**：乳胶漆白墙、浅木地板、棉麻布艺、哑光五金。
- **配色**：白 #FFFFFF / 浅灰 #D5D5D5 / 原木 #C4A574 / 黑色点缀 #1A1A1A。
- **适合**：小户型、预算有限、喜欢干净不折腾。
- **落地要点**：家具选细腿、低矮款显轻盈；收纳做整墙柜藏起来；点缀 1-2 件深色或绿植提气。

## 二、原木 / 日式（含 Japandi）

- **特征**：浅木色家具 + 奶油白，温暖治愈，wabi-sabi 侘寂 + 北欧 hygge。
- **材质**：橡木/白蜡木/樱桃木、竹、棉麻、藤编、纸质、石材。
- **配色**：奶油白 5Y 9/2 / 浅木 7.5YR 5/4 / 炭灰 N3 / 灰绿点缀 5GY 6/2。
- **适合**：小户型、追求温馨自然、喜欢「留白」。
- **落地要点**：家具低矮（床/沙发选低靠背）、留白留空（负空间是元素）、藤编+绿植+手工陶瓷点缀、灯光 2700–3000K 暖光。

## 三、奶油风（近年主流）

- **特征**：奶咖/米白柔和色调，温柔明亮，圆润线条。
- **材质**：微水泥/艺术漆墙面、弧形造型、羊羔绒/绒布、奶油色软包。
- **配色**：奶白 / 奶咖 / 燕麦 / 浅卡其 + 少量深棕压底。
- **适合**：年轻夫妻、女性偏好、想温馨不冷清。
- **落地要点**：墙面用奶咖乳胶漆（别用纯白）；家具选圆角、软包、低饱和；灯光 3000K 暖光；避免大块冷灰或金属冷色破坏柔和感。

## 四、北欧风

- **特征**：通透、浅色、功能主义、hygge 温馨。
- **材质**：白蜡木/橡木、羊毛、亚麻、羊羔绒。
- **配色**：暖白 N9.5 / 冷灰 N6 / 浅木 10YR 8/4 / 黑色点缀 + 软蓝 5PB 8/2。
- **适合**：采光好、喜欢清爽通透。
- **落地要点**：大窗不挂厚帘、多点暖光源、绿植+蜡烛、木地板浅色系。

## 五、轻奢 / 轻法

- **特征**：低调有质感，金属/玻璃/丝绒点缀，带轻法式线条。
- **材质**：黄铜/拉丝金属、大理石、丝绒、玻璃、皮革。
- **配色**：奶灰/米白底 + 金铜 #B08D57 + 墨绿/藏蓝点缀。
- **适合**：主卧、追求精致感、预算中上。
- **落地要点**：金属件统一色（全金色或全拉丝）；床头用软包/石膏线；避免大面积金光闪闪显土。

## 六、中古风（Mid-Century Modern）

- **特征**：有机曲线、锥形细腿、暖木色 + 复古色。
- **材质**：胡桃木、柚木、黄铜、皮革、玻璃纤维。
- **配色**：芥末黄 2.5Y 7/10 / 蓝绿 5BG 5/8 / 橙 5YR 6/12 / 橄榄 5GY 5/6 / 胡桃 7.5YR 3/4。
- **适合**：喜欢复古质感、有一定预算。
- **落地要点**：选一件标志性单品（如胡桃木边柜、曲线椅）当主角，其余从简。

## 七、风格混搭法则

**成功组合**：中古+北欧（同期、价值观近）、日式+极简（理念一致）、工业+中古（木+金属平衡）、奶油+原木（温润统一）。

**避雷组合**：极繁+极简（理念相冲）、工业+海岸（材质冲突）、传统中式+工业（气质相撞）。

**混搭口诀**：1 个主导风格占 70%，1 个辅助风格占 20%，点缀占 10%；配色统一；让硬装（地板/门/墙面）决定主风格。

## 八、风格选型决策树（快速定风格）

```
输入：房间大小、采光、预算、生活方式
├── 小房间(<15㎡) + 采光一般 → 北欧/日式（白墙+浅木+反光）
├── 大房间(>30㎡) + 预算足
│   ├── 传统取向 → 中古风（有分量的单品、质感材质）
│   └── 极简生活方式 → 日式/Japandi（低矮家具、大地色、留白）
├── 中等房间 + 有小孩 → 奶油风/现代简约（耐用面料、圆角、易打理）
└── 年轻夫妻自住 → 奶油风/原木（温馨、治愈）
```
