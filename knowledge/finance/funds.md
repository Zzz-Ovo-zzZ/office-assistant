# 指数基金清单（中国可投资标的）

> 全谱系产品清单：保本层（国债/定存/大额存单/货基/个人养老金）→ 增值层（宽基/行业/QDII 指数基金）。
> 本文件聚焦「增值层」的指数基金代码；保本层详见 guide.md 与 rates-2026.md。

---

## 一、为什么是指数基金

- 自动优胜劣汰：表现差的公司被剔除，后起之秀补位
- 从未有大盘指数基金破产或停止运营
- 90% 的主动基金 30 年内关门大吉
- 超额回报由最优秀的少数公司创造（二八定律）

## 六、全谱系产品分层（重要）

| 层级 | 产品 | 定位 | 建议比例参考 |
|------|------|------|------------|
| 保本层 | 储蓄国债 / 定存 / 大额存单 / 货基 / 个人养老金 | 短期资金、紧急储备金、保本需求 | 视资金期限 |
| 增值层 | 宽基 + 行业/QDII 指数基金 | 长期闲置资金，跑赢通胀 | 权益占长期资产的 70-100%（按年龄） |

> 紧急储备金（3-6 个月开支）必须放在保本层（货基/国债/定存），不要投入股市。
> 保本层「跑不赢通胀」是事实，但它的职责是**确定性**；增值层负责**增长**。二者按资金用途分工，不是二选一。

## 七、明确不推荐的产品

| 产品 | 不推荐原因 |
|------|-----------|
| P2P / 非标理财 | 高息陷阱，本金风险极高 |
| 加密货币 / 外汇投机 | 无长期内在价值，纯投机 |
| 个股（无研究能力） | 80% 跑输通胀，有破产风险 |
| 收藏品 / 艺术品 | 持有成本高、流动性差 |
| 3 倍杠杆 ETF | 长期衰变趋零 |
| 银行净值型理财 | 资管新规后不保本，收益又无优势（~4%） |
| 终身寿险 / 万能险 | 收益低（~3%）、流动性极差 |
